# Практична робота № 3: IDEF0-моделювання бізнес-процесів ІС

## Група:КС-24
## Варіант № 7: Продаж квитків на літак

### Склад команди:
* Кісільова-Чоларія Алевтина
* Ясінська Анастасія
* Гуржій Катерина

### Опис IDEF0-моделі (A-0):
* **Головний процес:** Обслуговування процесів продажу авіаквитків та розкладу рейсів
* **Input (Входи):** Запити пасажирів (маршрут, дати, клас салону, бюджет), параметри нових рейсів
* **Control (Управління):** Розклад рейсів, правила розрахунку цін за тип літака та комісії, правила пересадок
* **Output (Виходи):** Розрахована вартість квитка, оформлений авіаквиток, перелік доступних міст та маршрутів з 1 пересадкою, відомість цін
* **Mechanism (Механізми):** Пасажир, Оператор аеровокзалу, АСУ Продажу квитків та БД, Модуль пошуку стиковок
