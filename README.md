# Лабораторна робота 3

## CASE-засоби моделювання бізнес-процесів інформаційних систем Методологія IDEF0

**Група:** КС-24

### Команда

- Кісільова-Чоларія Алевтина
- Гуржій Катерина
- Ясінська Анастасія

## Мета роботи

Набути досвіду створення IDEF0-моделі бізнес-процесів за допомогою CASE-засобів моделювання.

## Предметна область

Предметною областю є система онлайн-бронювання готелів — **Hotel Online Booking System**.

Система забезпечує пошук і порівняння готельних номерів, перевірку їх доступності, оформлення бронювання та проведення оплати.

## Контекстна діаграма IDEF0

Контекстна діаграма A-0 представляє систему онлайн-бронювання готелів як єдиний функціональний блок.

### Вхідні дані Input

- запити користувачів;
- дати заїзду та виїзду;
- кількість гостей;
- критерії пошуку.

### Керування Control

- правила бронювання;
- політика скасування;
- тарифи;
- правила оплати.

### Вихідні дані Output

- результати пошуку готелів і номерів;
- підтвердження бронювання;
- інформація про статус оплати.

### Механізми Mechanism

- гості;
- адміністратори готелів;
- вебзастосунок;
- база даних;
- платіжний сервіс.

## Результат роботи

Було описано предметну область, визначено межі системи та її основні інформаційні потоки. Контекстна діаграма показує взаємодію системи із зовнішніми даними, правилами та ресурсами.

Для подальшої деталізації модель можна декомпозувати на процеси пошуку номерів, перевірки доступності, оформлення бронювання, оплати та управління замовленнями.

## Висновок

IDEF0-модель потрібна для наочного представлення функцій системи ще до початку її розробки. Вона допомагає визначити вхідні й вихідні дані, правила роботи, необхідні ресурси та можливі внутрішні процеси системи онлайн-бронювання готелів.
